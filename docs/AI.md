# 使用自己的大模型

CommitBrief 可以把当前纳入汇报的 Git 工作记录交给你选择的模型服务，生成可继续编辑的中文 Markdown 汇报。本地整理功能不依赖模型服务或 API Key。

## 配置步骤

1. 点击主界面的“模型设置”；尚未配置时点击“智能总结”也会打开设置。
2. 填写服务商提供的基础地址，例如 `https://api.openai.com/v1`。应用会补上 `/responses`，也支持填写完整接口地址。
3. 填写 API Key。同一接口已有保存的 Key 时可留空继续使用，也可清除后重新设置。
4. 点击“获取模型列表”从兼容的 `GET /models` 接口选择模型；服务不支持时可手动填写模型 ID。
5. 选择“简洁汇报”或“详细汇报”，按需测试连接，再保存设置。
6. 回到主界面，选择项目、时间和作者范围，核对工作项后手动点击“智能总结”。

**保存不会发送提交。** “测试连接”会向当前填写的地址与模型发送一条简短消息，不发送仓库记录；这是实际模型请求，可能产生服务商费用。连接成功不代表账户有足够额度处理长报告。

API Key 默认隐藏。点击输入框右侧的眼睛按钮会按需读取并显示当前保存的 Key，方便核对或修改；再次点击恢复隐藏。切换服务地址、清除 Key 或关闭设置窗口会退出明文显示状态。

## 兼容哪些服务

应用使用 OpenAI Responses 兼容格式：`POST /responses`，发送 `model`、`instructions`、`input`、`stream: false` 和 `store: false`，读取响应中的 `output_text`。Key 通过 Bearer 认证发送。

服务地址是否带 `/v1`、模型 ID 与 Key 格式，以所选服务的文档为准。没有兼容层的原生协议不能直接接入；当前不提供 Anthropic 原生 Messages 协议，也不支持额外认证参数、自定义请求头或地址查询参数。

远程服务必须使用 HTTPS 和 API Key。本机 `localhost`、`127.0.0.1`、`::1` 支持 HTTP；不需要认证的本机服务可不填 Key。请先自行启动兼容模型服务，再填写其实际地址和模型名称。应用不会安装或启动模型。

接口重定向会被拒绝，避免请求或密钥被转发到另一地址；请填写服务商提供的最终接口地址。

## 输入数据与选择范围

只有点击“智能总结”才会发送当前纳入报告的工作记录。搜索框只过滤列表显示，不改变报告或 AI 输入；排除某条记录需使用“从报告排除”，或调整项目、作者与时间范围。

| 内容 | 简洁汇报 | 详细汇报 |
| --- | --- | --- |
| 起止日期、项目/模块/工作项/提交数量 | 发送 | 发送 |
| 项目显示名、无路径的项目区分编号、模块、变更类型 | 发送 | 发送 |
| 修正后的工作描述、原始提交标题、完整 SHA | 发送 | 发送 |
| 提交正文 | 不发送 | 每条最多前 600 个字符，附截断标记 |
| 源码、diff、变更文件列表 | 不发送 | 不发送 |
| 作者姓名/邮箱字段、绝对仓库路径字段 | 不发送 | 不发送 |
| 右侧报告草稿 | 不发送 | 不发送 |

关闭“附上提交编号”会要求模型在输出中省略 SHA，但输入仍包含 SHA 以保留提交依据。同名项目以无路径的编号区分。

**文本没有自动脱敏。** 项目名、模块名、标题或正文中原有的邮箱、路径及其他信息仍会随文本发送。发送前请确认内容适合交给所选服务处理。

完整请求上限为 300 KB（300,000 字节），包含提示词和 JSON 数据。超过上限时不会调用服务，也不会静默丢弃提交；请缩短时间范围或减少项目。服务商可能有更小的上下文限制。

## 报告与原稿保护

AI 使用当前工作项生成一份新报告，不是续写右侧手动草稿。提示词要求按项目、模块与功能点组织中文，合并语义相关的工作，不编造未记录的业务收益、测试结果、上线状态或未来计划。原始统计与分类仍由本地记录决定，不由模型改写。

生成时显示等待状态，保留原稿并提供取消按钮；当前等待完整响应后才展示结果，不逐字输出。请求超时约为 120 秒。

成功生成后会备份上一份非空报告，可通过“恢复上一份报告”找回。服务错误、取消、输出截断或无效响应都不会替换原稿。生成期间编辑草稿、改变统计范围或保存新模型配置，会取消旧请求，旧响应不能覆盖新草稿。

模型报告会保存在本机，仍可继续编辑。提示词不能保证模型始终正确，请在复制或导出前核对事实。

## Key 保存在什么地方

API Key 保存在本机 macOS 钥匙串，以规范化后的完整接口地址区分；不写入普通配置文件或报告，不启用钥匙串同步。保存的项目设置、模型地址、模型 ID 和草稿存储在本机应用数据目录。

切换服务地址时，设置窗口不会读取或复制钥匙串中的 Key。API Key 留空保存时，模型配置会继续引用原接口的钥匙串条目；应用重启后仍可使用。要改用不同的 Key，请直接填写新值；此时才会写入新接口对应的条目。要移除已保存的 Key，请使用“清除已保存 Key”。

详细数据保存方式见 [隐私与数据说明](PRIVACY.md)。

## 常见错误

| 情况 | 建议 |
| --- | --- |
| 401 / 403 | 检查 Key 是否有效、是否过期，以及模型访问权限。 |
| 404 | 核对基础地址、完整接口路径和模型 ID。 |
| 429 | 检查服务额度，或等待后重试。 |
| 400 | 核对模型名称、协议兼容性，或缩短范围后重试。 |
| 服务返回重定向 | 填写最终接口地址。 |
| 响应格式不兼容 / 无有效内容 | 确认服务提供 OpenAI Responses 兼容的文本响应。 |
| 输出被截断 | 减少项目、缩短范围，或改用简洁汇报。 |
| 请求超过 300 KB | 减少当前报告包含的记录。 |
| 超时 / 无法连接 | 检查网络和地址；本机模型服务需先启动。 |
| 无法访问钥匙串 | 解锁本机钥匙串后重试。 |

0.3.3 已验证模拟接口下的请求、异常、跨地址凭据引用与草稿保护行为，未使用真实付费 Key 验证所有服务。不同服务的兼容性、中文表达与事实忠实度，需要在你选择的模型上核对。
