# 隐私与数据说明

适用于 CommitBrief 0.3.0。

CommitBrief 的基础整理在本机完成。应用没有账户系统、云端同步、遥测或广告服务；不会自动上传 Git 仓库。可选 AI 功能直接请求你配置的模型服务，不经过 CommitBrief 的中转服务器。

## 本地读取

添加仓库后，应用读取 Git 提交标题、正文、SHA、作者、提交时间、修改路径与变更数量，以及用于默认作者匹配的 Git 用户配置。它不读取未提交修改来生成报告，不修改仓库文件，不执行 fetch、pull、commit 或 push。

扫描只在你选择的目录内进行，最多向下 3 层；发现一个仓库后停止向其内部递归。要统计独立嵌套仓库，请另外添加。

## 本地保存

应用数据保存在当前用户的应用支持目录：

```text
~/Library/Application Support/CommitBrief/workspace.json
```

其中包括仓库路径与设置、作者筛选、模块与描述修正、排除记录、当前报告、上一份报告、最近 90 天的报告历史、模型服务地址、模型 ID、汇报风格和通知开关。**这个文件是普通本地配置文件，不是加密保管库**；报告和设置可能包含你的工作信息。原始 Git 日志会在使用时读取，应用不会另建一份完整仓库副本。

API Key 与 Webhook 地址分别存于 macOS 钥匙串，不写入上述文件。它们设置为仅当前设备、解锁时可访问，不启用钥匙串同步。应用不在对应请求之外转发这些值，也不在连接错误中展示它们。

复制报告会将内容写入系统剪贴板，导出会将内容写入你选择的文件。之后由其他应用、备份工具或用户主动分享产生的数据流转，不属于应用内同步。

从仓库列表移除项目不会删除磁盘上的仓库。移除应用本身也不等于清除其已保存配置和钥匙串条目。需要清理时，可先在模型设置中删除各接口保存的 Key，退出应用后再通过 Finder 管理上述应用数据目录；请先导出要保留的报告。

## 什么时候联网

| 操作 | 联网行为 |
| --- | --- |
| 添加或扫描仓库、读取日志、分类、编辑、复制与导出报告 | 不联网 |
| 填写并保存模型设置 | 不请求模型服务 |
| 点击“测试连接” | 向填写的接口发送简短测试消息，不含 Git 记录 |
| 点击“智能总结” | 向所配置接口发送当前纳入报告的工作数据 |
| 手动更新报告且已启用 Webhook | 向配置的 Webhook 发送标题、日期范围和统计数量，不含报告正文 |
| 点击“检查更新” | 向 GitHub Releases API 查询最新正式版本号 |

模型调用可能产生服务商费用。服务商如何保留和使用请求数据，取决于你选择的服务及账户设置；CommitBrief 无法替服务商保证保留期限或训练策略。

远程模型与 Webhook 接口必须使用 HTTPS；HTTP 只允许本机回环地址。模型、Webhook 和更新检查请求不跟随重定向，不使用应用内持久化 Cookie 或响应缓存。实际生成的报告会按草稿和历史功能保存在本机。

## 智能总结的数据范围

两种汇报风格都发送所选范围的日期与数量、项目显示名、项目区分编号、模块、变更类型、工作描述、原始提交标题和完整 SHA。详细汇报额外发送每条提交正文的前 600 个字符，并标记是否截断；简洁汇报不发送提交正文。

不会单独发送作者姓名/邮箱字段或绝对仓库路径字段；也不会发送源码、diff、变更文件列表或右侧报告草稿。API Key 用于认证你选择的服务，不放进报告输入数据。

这些限制是对发送字段的限制，**不是自动脱敏**。如果项目名、工作描述或提交文本本来包含邮箱、路径、内部项目名称或密钥等内容，原有文本仍可能被发送。请在调用前核对记录，必要时排除相应提交。

搜索框只隐藏列表中的不匹配项，不会把它们从报告或 AI 请求中排除。调整项目、时间、作者范围，或使用“从报告排除”，才能改变发送范围。关闭“附上提交编号”只影响模型输出要求，不会从输入中删除 SHA。

取消请求可以阻止后续结果覆盖草稿，但无法撤回已经发送给服务商的数据。需要完整离线使用时，请保持本地整理，或配置在本机运行的兼容服务。

## 公开反馈

本 GitHub 仓库、Issue 和 Release 页面公开可见。反馈时请使用虚构或脱敏示例，不要提交 API Key、私有代码、内部提交记录或包含账户信息的截图。

对应用行为有疑问，可在 [Issues](https://github.com/GpsLypy/CommitBrief/issues) 描述不含敏感数据的复现步骤。
